MovieThrow
Changelog.

A user-facing record of new features, improvements, and fixes in every public version.

Version 1.6 LATEST

August 19, 2026
  • Newly queued movies and episodes now reliably begin at the start instead of jumping minutes ahead.
  • Fresh streams build a short cushion before playback for smoother, more resilient delivery.
  • An empty Player now makes the Library the primary choice while retaining access to files elsewhere.
  • Expanded local library, title details, cast and crew, artwork, extras, and metadata-management tools.
Release and download →

Version 1.5.1

August 19, 2026
  • Fixed a startup deadlock that could freeze or close MovieThrow when opening a movie or episode.
  • Hardened playback completion, stall, and failure handling for safer interface updates.
Release and download →

Version 1.5

August 15, 2026
  • Added rich movie and episode details with runtime, genres, cast, characters, crew, and linked headshots.
  • Movies and shows now open a detailed preview before playing or joining Up Next.
  • Added fully local metadata and poster editing that works independently of TMDb.
  • Added classification correction and grouping for trailers, featurettes, deleted scenes, and other extras.
  • Improved metadata matching, sleep/wake subtitle recovery, and writable library management.
Release and download →

Version 1.4

July 30, 2026
  • Introduced the local media library with movies, shows, seasons, episodes, and whole-season queueing.
  • Added automatic filesystem updates, search, duplicate review, safe renaming, Finder access, and Trash support.
  • Added local artwork and optional high-confidence TMDb poster matching.
  • Added OpenSubtitles alternatives and fallback subtitle generation.
  • Improved caption reliability, HDR/4K AirPlay routing, seeking, and playback compatibility.
Release and download →

Version 1.3

July 29, 2026
  • Added automatic captions from embedded tracks, local files, OpenSubtitles, or fallback generation.
  • Added persistent, plain-language caption status and broader text and bitmap subtitle support.
  • Improved AirPlay startup, seeking, buffering, timelines, and recovery.
  • Added queue file dropping, ten-second skip controls, cleaner titles, and more useful technical details.
Release and download →

Version 1.2

June 26, 2026
  • Added selectable multi-track subtitles, including language switching over AirPlay.
  • Improved Apple TV handoff so playback waits for the selected television instead of briefly starting on the Mac.
  • Polished scrub previews, the AirPlay chooser, connected-device naming, and filename display.
Release and download →

Version 1.1

June 26, 2026
  • Added timeline scrub-preview thumbnails.
  • Added live now-playing artwork that follows the current scene.
  • Preview imagery is generated in the background and cached locally for reuse.
