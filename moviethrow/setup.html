Add a TMDb token

For automatic posters, title details, cast, and crew.

  1. Create or sign in to a TMDb account.

    Visit themoviedb.org and complete any email verification TMDb requests.

  2. Open TMDb’s API settings.

    Go to Settings → API. If TMDb asks you to request API access, follow its form and describe personal MovieThrow use.

  3. Copy the API Read Access Token.

    Copy the long token labeled API Read Access Token. Do not copy the shorter API Key; MovieThrow expects the Bearer token.

  4. Open MovieThrow Settings.

    Choose MovieThrow → Settings… from the menu bar, or press ⌘,.

  5. Save it under Official poster artwork.

    Paste the token into TMDb API Read Access Token, then click Save poster token.

  6. Fetch artwork.

    Return to the Library and click Posters. MovieThrow will identify high-confidence matches and fill title details as you browse.

Your token stays in your Mac login keychain.

MovieThrow uses it for title identification, details, and missing official artwork. Existing local artwork and your manual metadata overrides remain authoritative.

CC

Add an OpenSubtitles API key

For automatic subtitle search and selectable alternatives.

  1. Create or sign in to an OpenSubtitles.com account.

    Use OpenSubtitles.com. This is the .com service, not the older .org site.

  2. Create an API consumer.

    Open your API consumers page, choose New Consumer, and complete the short application form.

  3. Copy its API key.

    Once the consumer is created, copy the generated API key.

  4. Open MovieThrow Settings.

    Choose MovieThrow → Settings… from the menu bar, or press ⌘,.

  5. Save the OpenSubtitles credential.

    Paste it into the API key field under OpenSubtitles, then click Save credentials. The Bearer token field is optional and may be left empty.

  6. Choose your subtitle preferences.

    Turn on Find missing subtitles automatically and enter a two-letter preferred language code such as en, fr, or es.

Your media is not uploaded.

MovieThrow searches using a lightweight file hash, stores credentials in your Mac login keychain, and downloads a subtitle only when a match is selected. OpenSubtitles account limits still apply.
